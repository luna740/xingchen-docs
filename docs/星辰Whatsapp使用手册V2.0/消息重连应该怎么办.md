# 消息重连应该怎么办

更新时间：2026-09-23T18:55:00+08:00

## 一、后管系统操作

在线状态的账号都会显示“修复”按钮。

点击“修复”按钮，页面提示修复成功即可。

![后管系统修复入口](../../site/assets/images/aHEM43l6NN.png)

![后管系统修复成功](../../site/assets/images/MqgGYKN1Lh.png)

## 二、坐席系统操作

1. 在账号列表中选中需要处理的账号并点击右键。
2. 选择“修复账号”。
3. 页面提示修复账号成功后，完成消息重连。

![坐席系统修复账号入口](../../site/assets/images/GjYpSxF3KJ.png)

![坐席系统修复成功](../../site/assets/images/1ccAgVt3SR.png)
